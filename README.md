# Projeto ESG - Educacional

## Descrição
Site educacional sobre ESG (Ambiental, Social e Governança) com página explicativa e quiz interativo para validar aprendizado.

## Como Usar
1. Abra `index.html` no navegador.
2. Navegue entre "O que é ESG" e "Quiz".
3. No quiz, responda às 10 questões para ver seu resultado.

## Requisitos
- HTML5, CSS3 e JavaScript vanilla
- Funciona offline (sem dependências externas)
- Acessibilidade e responsividade implementadas
